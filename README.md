# Fluentian — Premium French Learning App

This is the starting project skeleton for Fluentian, featuring the core design system and theme configuration.

## Project Structure

- `lib/main.dart`: Entry point with theme initialization.
- `lib/core/`: Design system, themes, and constants.
- `pubspec.yaml`: Project dependencies and metadata.

## Setup

1. Ensure you have the Flutter SDK installed.
2. Run `flutter pub get` to install dependencies.
3. Run `flutter run` to start the app.
